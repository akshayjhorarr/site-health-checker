# Site Health Checker 🩺

A real-time website diagnostic tool that checks
performance, SSL, availability, and response time
for any website URL.

## 🔗 Live Demo
[View Live Tool](https://akshayjhorarr.github.io/site-health-checker)

## 💡 About This Project
Built to simulate real-world website health checks
that WordPress support specialists perform when
diagnosing customer site issues.
Enter any URL and get instant diagnostic results.

## 🛠️ Features
- Live HTTP request with real response time measurement
- Animated health score (0–100) with ring visualization
- Step-by-step loading progress animation
- 8 diagnostic checks — Pass / Warn / Fail / Info
- SSL & HTTPS detection
- Smart recommendations based on results
- Quick-test buttons for popular WordPress sites

## 📂 Checks Performed
- ✅ Site Reachability
- 🔒 SSL / HTTPS Status
- ⚡ Response Speed
- 🌐 Domain Resolution
- 🔗 URL Format Validation
- 📡 Connection Stability
- 🛡️ Protocol Security
- 🔍 WordPress Site Detection

## 🧰 Built With
- HTML, CSS, JavaScript
- No frameworks, no dependencies
- Live fetch API for real measurements
